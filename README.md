# SmartWarehouse 360

Первое значительное приложение, созданное в рамках выполнения курсовой работы. Его основная цель — учёт поступления товаров на склад.
При первом запуске приложение проверяет, подключено ли оно к локальному серверу, и, если подключение установлено, автоматически создаёт базу данных, если она ещё не существует. 
Настройки подключения можно найти в настройках проекта.
В базе данных хранятся сведения о сотрудниках, поставщиках, накладных, товарах, а также о категориях товаров.
